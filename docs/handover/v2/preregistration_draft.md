## 草稿 A：总更新预算匹配，未冻结

为 D3/D4 固定相同总更新数 U（数值未冻结）、accum=A（未冻结）、math/code block顺序及每域生成上限。相同 seed 的题目计划一致，域内顺序不因教师表现而改变。按模型 `(model,revision)` 识别驻留教师，D3 两域共用教师无需重载，D4 实际切换计成本。

主比较为双域 dev/固定官方测试的能力差异及跨域退化。分别报更新数、每域 prompt/有效 response tokens、function/stdio 曝光、rollout tokens、教师前向/切换/纯计算/保存时间、总墙钟、显存与 removed mass。生成长度是响应变量；更新预算相同不保证实际 token 成本相同。D1/D2 与混合组的每域曝光不可直接等同。

## 草稿 B：曝光匹配，未冻结

明确“曝光”首先指每域见到的题目数，按共同计划为 math/code 各固定 E 个 prompt（E未冻结），function/stdio 实际数量另报。单域诊断组为匹配目标域曝光可使用不同总更新数；单域对混合组不作为纯教师数因果比较。
