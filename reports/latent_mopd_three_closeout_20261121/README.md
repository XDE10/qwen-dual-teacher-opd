# 三教师 Latent-MOPD 收尾结果

最终评测使用本地 **70 步**。学生是 DeepSeek-R1-Distill-Qwen-1.5B，冻结教师分别负责数学、代码、逻辑。训练与推理 checkpoint 的运行身份在其归档清单中记录。

## 选 70 步

- 固定开发集小样本每域 32 题，60、70、80 步三域等权均值为 **72.92%、72.92%、68.75%**。这是低成本筛选，配对区间包含零。
- 60 与 70 步扩充到 256 道数学题，经过明确等价答案复核后为 **211/256 与 224/256**。70 截断较少，双方都完成的 215 题上为 **204/215 与 206/215**。
- 128 题配对代码开发集为 **73/128 与 72/128**，逻辑为 **83/128 与 81/128**。这两项的区间跨零，三域一起考虑后选择 70 步。

## 重测记录

- **MBPP / MBPP+** 同题两次生成，原提示的宽松复核为 24.21% / 20.37%。针对推理输出与函数接口调整提示后，在同一 EvalPlus 0.3.1 上通过 536/756 与 443/756。
- **LCB-e** 在实际计分的 67 题上重跑，明确 starter 接口、stdin/stdout 和完整程序要求。相同测试从 190/268 变为 196/268，两种代码提取都给出 196。
- **MuSR** 单次生成的物品追踪重测答对 115/250，谋杀与团队沿用同权重原输出的 268/500。对统一最终字段中明确写出的选项复判后为 383/750，初判为 380/750。原分保留。
- **GYM** 70.52% 是本地重建题集的验证器均分，621/925 拿满分。部分分贡献 3.39 个百分点。作者未公开逐题清单，本地题集与论文只能并列参考。
